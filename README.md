## ⭐ Core Projects

### 基于 CBDB 的中国古代士人仕途与科举预测研究

这是仓库中较为完整的研究型项目之一。

项目尝试将中国古代历史数据、CBDB（中国历代人物传记资料库）、数据分析与机器学习结合，对古代士人的仕途与科举相关问题进行探索。

主要涉及：

* 数据获取与整理
* 数据清洗
* 数据分析
* 特征工程
* 机器学习
* 模型训练
* 模型评估
* 数据可视化

```text
中国古代历史数据
        +
CBDB
        +
数据分析
        +
机器学习
        ↓
古代士人仕途与科举预测研究
```
